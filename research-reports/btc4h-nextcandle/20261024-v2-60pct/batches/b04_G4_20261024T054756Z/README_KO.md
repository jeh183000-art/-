# BTCUSDT 4시간봉 다음 봉 예측 V2 — 실제 적중률 60% 목표

이 프로젝트는 현재 4시간봉 마감 시점까지의 정보로 다음 4시간봉의 종가가 그 봉의 시가보다 높은지 예측한다. 다음 종가와 현재 종가를 비교하는 문제가 아니다. 주문이나 매매 수익률을 계산하지 않는 분류 연구다.

## 이번 연구의 판정 기준

사용자 목표는 실제 예측 적중률 60% 이상이다. 전체 봉을 예측하는 경우와 조건을 만족할 때만 예측하는 경우를 구분한다. 모델이 표시하는 60% 확률만으로 목표 달성을 선언하지 않는다.

표본과 시기 분산 기준은 이번 연구에서 추가로 정한 기본값이며, 사용자가 직접 지정한 수치가 아니다. 개발 기간은 2024년과 2025년 각각 200회 이상, 매월 최소 5회가 나온 달이 8개월 이상, 한 달에 전체 신호의 25%를 초과해 몰리지 않는 조건으로 비교한다. 2026년 1~9월 평가는 200회 이상, 활성 월 6개월 이상, 월 집중도 25% 이하에서 관측 적중률 60% 이상을 목표 통과로 기록한다. 이는 미래의 실제 적중률이 항상 60% 이상이라는 보장이 아니다.

2024·2025년은 이전 연구에서 이미 본 자료이므로 개발 자료로 취급한다. 2026년 1~9월은 이 V2에서 후보 선택 전에 성능을 확인하지 않는 별도 평가 자료다. 사용자의 모든 과거 연구를 통틀어 처음 보는 자료라고 주장하지 않으며, 다른 프로젝트의 보호된 Final OOS에는 접근하지 않는다.

## 고정한 탐색 범위

- 개발용 입력: 2020~2025년 BTCUSDT 4시간봉·15분봉, ETHUSDT 4시간봉.
- G1: 기존 4시간봉 특징 38개.
- G2: 가격 구조·변동성·매수 체결 변화 등 추가, 총 77개.
- G3: 현재 확정 4시간 구간 안의 15분봉 16개 흐름 추가, 총 104개.
- G4: 정확히 같은 시각에 확정된 ETH 상대 정보 추가, 총 122개.
- 그룹마다 학습 설정 10개: 로지스틱 회귀, 작은 부스팅, ExtraTrees, RandomForest, SVC의 고정 설정.
- 그룹마다 사전 고정한 평균 앙상블 4개.
- 총 학습 설정 40개, 앙상블 16개, 예측 구성 56개.
- 각 예측 구성에 선별 기준 8개를 적용하므로 **개발에서 비교하는 구성·기준 조합은 448개**다.

선별 기준은 고정 확률 50%, 52.5%, 55%, 57.5%, 60%, 62.5%와 과거 보정 자료의 확신도 분포 70·85분위 기준이다. 분위 기준은 예측 대상 분기의 순위를 미리 보고 정하지 않는다. 과거 보정 자료에서 정한 기준값을 다음 분기에 적용한다. 보정 확신도가 상수이면 분위 기준은 모두 관망한다.

## 시간순 학습·선택·평가

각 분기 이전 180일을 기본 모델 학습과 분리된 확률 보정에 사용한다. 기본 모델의 학습 창은 설정별로 730일 또는 이전 전체 이력이다. 학습 정답 확정 시각은 보정 시작보다 앞서고, 보정 정답 확정 시각은 평가 시작보다 앞서야 한다.

결측값의 중앙값과 표준화 수치는 해당 기본 모델 학습 구간에서만 학습한다. 확률 보정은 규제가 있는 로지스틱 함수로 한다. 보정 기울기가 0 이하이면 방향 순서를 뒤집지 않고 과거 보정 구간의 평활 양봉 비율을 상수로 출력한다. 모든 기울기와 분포를 기록한다.

개발은 G1~G4를 배치로 나눠 실행한다. 2024년과 2025년의 각 분기 예측을 모아 표본·시기 분산 조건을 통과한 조합 중 낮은 연도 적중률이 가장 높은 조합을 선택한다. 동률 처리와 세부 조건은 `settings.json`에 있다. 개발에서 60%에 못 미쳐도 최고 적격 후보 하나를 사전에 고정한 다음 2026년에 한 번 평가한다. 적격 후보가 하나도 없으면 새 평가 자료를 열지 않는다.

2026년 평가 후 다른 후보로 바꾸거나 같은 평가 기간에 맞춰 조정하지 않는다. 이전 V1과 단순 기준은 사전 지정된 비교 목적으로만 평가한다. 선택한 바로 그 시점에 항상 양봉, 항상 음봉, 과거 다수 방향, 현재 봉과 같은 방향·반대 방향을 예측했을 때의 결과도 함께 계산한다.

## 실행과 원장

`python engine_v2.py --help`로 단계별 명령을 확인한다. 개발 배치는 `--phase development --group G1`부터 G4까지 실행하며, 선택과 최종 평가는 별도 단계다. 완료한 결과를 덮어쓰지 않는 새 결과 폴더를 사용한다.

모든 후보와 실패, 신호 0개인 기준을 포함한 결과 CSV를 남긴다. 예측 원장은 봉당 한 행으로 저장하고 월별 gzip 파일로도 나눈다. 최종 선택 파일은 설정·코드·입력·개발 결과 해시를 포함한다. 원본 시세는 공식 URL과 체크섬으로 재현하며 공개 저장소에 중복 업로드하지 않는다.

원본 4시간봉과 15분봉 합산값의 기존 4개 구간 차이는 출처 진단으로 보존한다. 공식 4시간봉이 정답 기준이며, 결과에 맞춰 원본을 교체하거나 보간하지 않는다.

## 비교·한계

이전 4시간봉 V1은 2025년 전체 50.96%, 55% 기준 51.04%, 60% 기준 61.36%(44개 모두 1분기 양봉 예측)였다. 이 V2는 개선을 시도하는 별도 연구이며 목표 달성 여부는 실제 결과 보고서에서 판정한다. 과거 수치가 높다는 이유로 현재 적중률 또는 수익률을 보장하지 않는다.

향후 매매 검증은 별도의 문제이며 사용자가 정한 왕복 수수료 0.12%, 실제 펀딩과 체결 지연·슬리피지가 필요하다. 이번에는 수익률·PF·MDD를 계산하지 않는다. 실행 환경은 제공된 클라우드 Linux이며 사용자 Windows C:/D: 또는 WSL은 접근하지 않는다. Windows 재현은 기존 지시에 따라 D 드라이브의 Codex_Research 하위에서 수행한다.
