# 가격 의미·월물·시각 검증

KIS 공식 commodity_futures_realtime_quote 검사용 예제의 고정 커밋2077773a69a428daf63e148182511f068cc45de3에서 futs_askp1=선물 매도호가1, futs_bidp1=선물 매수호가1을 확인했습니다. [공식 코드](https://github.com/koreainvestment/open-trading-api/blob/2077773a69a428daf63e148182511f068cc45de3/examples_llm/domestic_futureoption/commodity_futures_realtime_quote/chk_commodity_futures_realtime_quote.py). 이는 현재 공식 필드 의미이며2025년 제3자 생성 코드와 동일했다는 입증은 아닙니다.

제3자 로그는 선물 매도가를 ask·매수가를 bid, 테더 매수가를 실행 ask·매도가를 실행 bid로 가정합니다. 생성 코드·버전이 없어 실제 라벨 매핑은 확인하지 못했습니다. 공식 필드를 쓰는 다른 상품도 있으므로 오류 문구와 유사한 가격만으로 미국달러선물을 인증하지 않았습니다. 미국달러선물1계약10,000 USD도 이 PAPER의 명시적 가정입니다. 역전 호가는 임의로 뒤집지 않고 제외했습니다.

이전 감사의 현재 트리 전체와 삭제 이전README 조사 외에, 이번에는1월10일 로그의 제한된 과거 변경 기록과 당시 전체트리(53항목,잘림없음)를 확인했습니다. 실행 코드나 설명 문서는 발견하지 못했습니다. 모든 과거 버전에 코드가 없었다고 단정하지 않습니다. source_evidence.json에 API 경로·커밋·해시·조사 범위를 저장했습니다. 소스의 스크립트를 실행하지 않았고 인증정보를 사용하지 않았습니다.

기록시각은 KST라고 가정했으며 실제 시세시각·요청 간 동시성·거래소·월물·만기를 확인하지 못했습니다. 공식 거래일·최근월물 참조표는 필터와 위험 경계에만 사용했으며 로그의 계약을 그 코드로 인증하지 않았습니다. 경계11개와 중앙값 차이 분포는 boundary_jumps.csv와 post_verification.json을 참조하십시오. 최대37.65원은 공백 구간과 월물 효과가 섞인 가능성이 있어 이상 가격으로 수정하거나 조정하지 않았습니다.

Q4 기존 공식 분봉·업비트와의 비교는 이전 고정 감사에서 이미 검산한24개 가격 필드·월 그룹의220,936개 비교를 재사용했습니다. cross_comparison_distribution.csv에 시가·종가 대비 차이의 평균·중앙값·1/99백분위·극값·정확히 같은 건수가 있습니다. 원문 호가와 분봉 시가·종가는 다른 관측이므로 같은 값이거나 가까운 값이어도 출처 인증이 아니며, 다른 값도 자동 오류로 판정하지 않습니다. 시간대 가정과 월물 미확인이 유지됩니다. 원본 시계열과 섞지 않았습니다.
