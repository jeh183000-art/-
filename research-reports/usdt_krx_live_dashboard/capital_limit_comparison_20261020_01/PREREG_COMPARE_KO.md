# 비교조건 정정 v2 — 최대 17계약 분할 진입 vs 최초 17계약 일괄 진입

상태: PREPARED / NOT EXECUTED. 사용자 정정에 맞춘 실험 설계이며 재백테스트 실행 결과가 아니다. 이 경로의 이전 설계는 Git 이력에 보존한다. 기존 결과·원장·전략 코드는 덮어쓰지 않는다.

## 사용자 의도와 이전 설계의 오류

사용자가 비교하려는 것은 다음 두 방식이다.

- 추가매수 있음: 최초 1계약, 이후 0.2%p 단계마다 1계약씩 추가하여 최대 17계약.
- 추가매수 없음: 최초 진입 신호에서 현물과 선물 모두 17계약 상당 수량을 한 번에 진입하고, 청산 전 추가 진입 없음.

'추가매수 없음'은 '최대 1계약'이라는 뜻이 아니다. 한 번의 진입 주문 묶음에 17계약을 넣을 수 있다. 따라서 이전 설계의 17계약 분할 대 1계약 일괄 비교는 사용자가 요청한 주 비교가 아니며 폐기한다. 임의로 제안했던 현물 3,000만원 상한도 이번 주 비교에 적용하지 않는다.

## 고정 비교 조건

| 항목 | A: U-007206-CAP17 | B: S1-050-LUMP17 |
|---|---|---|
| 선물 초기현금 | 30,000,000원 | 30,000,000원 |
| 최초 선물 수량 | 1계약 | 17계약 |
| 최초 현물 수량 | 10,000 USDT | 170,000 USDT |
| 추가진입 | 괴리율 0.2%p마다 1계약 + 10,000 USDT | 없음 |
| 최대 동시 보유 | 17계약 + 170,000 USDT | 17계약 + 170,000 USDT |
| 방향 | 정배만 | 정배 또는 역배, 동시에 양방향 보유 금지 |
| 최초 신호 | -0.8% 하향 통과 | -1.0% 하향 통과 정배 / +1.0% 상향 통과 역배 |
| 청산 신호 | -0.5% 이상 회복, 전량 | 실제 진입 신호 괴리율에서 0.5%p 유리하게 회복, 전량 |
| 전략상 손절·보유시간 제한 | 기존 규칙대로 없음 | 기존 규칙대로 없음 |

주 비교는 선물 초기자금과 최대 계약 수를 맞춘 두 기존 전략의 비교다. 진입 임계값·청산 방식·거래 방향 및 시간별 노출은 서로 다르므로, 수익 차이가 추가매수 여부 하나 때문이라고 단정하지 않는다. 순수한 분할/일괄 효과를 분리하는 같은 신호 대조 실험은 별도 등록 없이는 이번에 추가하지 않는다.

현물 초기자금은 사용자가 확정한 금액이 없으므로 3,000만원이나 다른 숫자로 임의 고정하지 않는다. 이번에는 양쪽에 동일하게 충분한 현물 조달능력이 있다고 가정하고 각 전략의 필요 현물자금을 별도 산출한다. 이는 동일 총자본·동일 평균투입금 실험이 아니라 동일 최대 노출 실험이다. 현물 자금이 실제로 확보됐다고 표현하지 않는다. 역배의 170,000 USDT 차입 가능성과 차입비용이 미검증이면 B 전체를 차입 미검증 이론값으로 표시한다.

## 실행 전 확인과 자금 제한

1. 기존 승인 EXPLORATORY 자료만 사용한다. 공통 시세 SHA-256: 62becd7d50e05bdcf47010cdcdfdd8178bbe2ef1d8099a84ab18fae8fea19fbd. 기존 승인 KRX 거래일 2026-01-01~10-15 및 확인된 야간 경계만 사용하며 Final OOS는 열지 않는다.
2. 원래 U-007206와 1계약 S1-050을 먼저 재현하여 기존 59사이클 및 45사이클·비용·손익 원장과 대조한다. 기존 1계약 결과는 변경하지 않는다.
3. A에는 17계약 상한을, B에는 최초 고정 17계약 주문을 적용한다. B의 현물 수량만 또는 선물 수량만 늘리면 안 된다. 한 방향의 주문 묶음만 보유하며, 보유 중 신규 신호는 무시한다.
4. 선물 초기현금은 두 전략 모두 3,000만원이고 추가 입금이나 현물계좌에서의 자동이체는 없다. 당시 초기·유지증거금 일정, 일일정산, 거래비용과 누적 현금을 반영한다. B의 최초 17계약 주문이 신규 증거금 조건을 만족하지 못하면 주문을 전부 거절하고 기록한다. 1계약 또는 가능한 수량으로 몰래 축소하지 않는다.
5. 유지증거금 부족과 실제 강제청산을 구분한다. 증권사 반대매매 절차가 미지정이면 실제 청산을 구현했다고 주장하지 말고 첫 부족 시각·금액 및 이후 가상 보유 경로를 구분하여 보고한다. 부족 후 계속 보유한 가상 수익을 실행가능한 성과로 합격 처리하지 않는다.
6. 종가 신호 이후 다음 실제 연속 관측분 시가를 체결 대용으로 사용한다. 결측 보간·소급 신호 금지. 기존 롤오버 및 불연속 구간 규칙을 유지한다.
7. 현물 수수료·청산수수료·슬리피지는 수량에 비례 적용하고 선물 편도 600원은 계약당 부과한다. 따라서 17계약이면 해당 비용도 17계약분이다. 롤오버 구계약 청산과 신계약 진입의 양쪽 비용을 반영한다. 역배 차입비용 미반영을 숨기지 않는다.

## 성과와 위험의 표시

- 주 점수는 완료 사이클별 비용 차감 순손익 / 해당 사이클 현물 진입금액 절대값 합계 ×100을 반올림 전 단순 합산한다. 투자금·증거금으로 분모를 바꾸지 않는다.
- 실제 원화 순이익, MDD, 최대 평가손실, 최대/평균 노출, 현물 필요자금, 선물 증거금 여유 최저치, 진입 거절 및 유지증거금 부족 횟수, 보유시간, 미청산 손익을 함께 보고한다.
- B의 정배·역배 기여도를 실제 통합 실행 원장에서 분리한다. 별도 단방향 실행의 결과를 단순 합산하지 않는다.
- 참고로 기존 S1-050 1계약의 원화 순이익은 1,903,331.04513901원, MDD는 550,000원이다. 같은 체결 경로·선형 비용·자금제약 없음 가정에서 17배 비례 환산하면 각각 약 32,356,627.77원과 9,350,000원이다. 이것은 산술 참고값이지 3,000만원 계좌 제한을 적용한 재검증 결과가 아니다. 수익률 점수는 수량만 17배로 늘린다고 17배가 되지 않는다.
- 기존 U-007206 원화 순이익 10,821,261.44원과 MDD 4,958,425.27원 역시 기존 관측값이며 새 제한 재실행과 구분한다.
- 이전 대화의 '최초 진입 대비 +9.6%'는 검증된 안전 한계가 아니다. 특히 분할 진입 가정을 최초 17계약 일괄 진입에 적용하지 않는다. 같은 계약 상한이어도 진입 시점과 평균단가가 달라 위험 경로가 다르다.
