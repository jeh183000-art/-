재현 순서: Node로 code/download.mjs 실행 → Python으로 code/bootstrap.py audit_logs.py → compare_existing.py → additional_quality.py → package_audit.py. 원본 tree 메타데이터는 provenance의 고정 커밋에서 GitHub 공식 git/trees API로 저장한다. frozen_scope.json 설정과 기존2025년 비교 입력을 D:에 준비한다. 필요한 기존 참조 자료는 reference_input_hashes.csv와 정확한 SHA로 확인한다. 다운로드 시 기존 blob·크기 일치 파일은 재사용하며 원문을 덮어쓰지 않는다. 파서는 own derived_local만 다시 생성할 수 있다. code 디렉터리를 별도 D: root에 두고 metadata·raw·출력도 같은 root에 둔다. 공개 원문을 실행하지 않는다. 일부 입력은 재배포 권한 미확인으로 D:에만 있어 이 패키지 단독의 완전한 원문 재현을 보장하지 않는다. 전략 실행 코드는 포함하지 않았으며 모든 분석은 가격 로그 품질 감사이다.
