# 검증 범위와 코드 점검 기록

수치 검증의 통과 여부는 regression.json, independent_validation.json,
independent_fill_validation.json 및 합성 테스트 실행 결과로 판단한다.
독립 검산은 시뮬레이터를 import하지 않고 원본 CSV와 증거금 일정을 직접 읽는다.
이는 원장 계산의 독립 검산이며 독립 기간의 전략 성과 검증은 아니다.

코드 파일은 각각 200줄 미만의 비주석 코드로 분리했다.
계좌 상태·시세 순회·회귀 대조·원장 검산·위험 집계·게시 패키지는 별도 파일이다.
실행 중인 동결 계산 코드는 스타일 개선 목적으로 변경하지 않았다.

프로그래밍 스킬의 정적 스타일 검사에는 알려진 지적이 남는다.
- Lot, Accounts는 정산 기준가와 현금의 변화를 기록하는 의도적인 가변 상태다.
- Outcome은 가변 계좌 상태와 원장 목록을 함께 반환하는 실행 결과다.
- CSV 경계의 mark/regression 반환은 동적 열 집합을 갖는 사전이며 정적 TypedDict로 제한하지 않았다.
- 문자열 CSV 이벤트/평가 구분의 알 수 없는 값은 AssertionError로 거절한다.
  assert_never 기반 정적 폐쇄형 열거를 사용하지 않았다.

따라서 정적 스타일 검사 또는 전체 엄격 타입 검사가 깨끗하다고 주장하지 않는다.
실행환경이나 기존 연구 엔진을 변경해 이 지적을 감추지 않았다.
위 내용은 수치 원장 대조의 실패를 뜻하지 않으며, 동결 소스 해시와 실행 결과를 그대로 보존했다.
