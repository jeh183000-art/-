# B 신규 사전등록 항목수 검사 수정

기준 커밋의 실행 결과1000행과 설정집1001항목은 모순이 아닙니다. 추가1개는 CONTROL-S1-050-LUMP17 회귀 대조입니다. 등록기의 잘못된 단순항목수 검사를 실제 실행후보1000개와 별도 회귀 대조1개 검사로 분리했습니다. 원격 결과CSV와 설정집 SHA를 다시 확인했으며 1001개 규칙 모두 중복제외에 사용합니다. 기존B·나머지 후보·매매 엔진·비용·검산기는 변경하지 않았습니다. 수정 전 신규 시장 전략 실행0건, 수치 검산과 B 회귀는 모두 PASS입니다. 수정된 첫50조건은 사전등록 이후 실행하며 기존코드v1은 보존합니다.
