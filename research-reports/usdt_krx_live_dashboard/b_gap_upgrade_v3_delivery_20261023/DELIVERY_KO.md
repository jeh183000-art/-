# Codex 전달용 — ZIP 첨부 없이 원본 v3 코드 받기

이 폴더는 코드 전달 패키지다. 2025년 실제 가격으로 새 검증을 실행한 결과가 아니다.

ZIP 안의 Python 4개와 README 1개를 바이트 변경 없이 게시했다. 별도 manifest.json에 파일 크기, SHA-256, Git blob SHA-1을 기록했다. 원본 ZIP 자체는 이 GitHub 폴더에 포함하지 않는다. ZIP이 없어도 다섯 파일을 같은 디렉터리에 받으면 된다.

## Codex 작업

1. 이 폴더가 들어 있는 불변 커밋에서 manifest.json과 다섯 파일을 기존 파일이 없는 새 D: 코드 폴더로 받는다. 원격 읽기 권한으로 다운로드할 수 있으며 main으로 체크아웃하거나 기존 연구를 덮어쓸 필요가 없다.
2. 다운로드한 원본 바이트의 크기와 SHA-256을 manifest.json과 대조한다. git 체크아웃의 CRLF 변환은 해시 차이를 만들 수 있으므로 원본 바이트를 보존한다.
3. 코드를 검토한다. README의 '세 파일' 표현은 오기이며 Python 파일은 네 개다. README의 '실수익 검증'은 실제 운용 성과를 의미하지 않는다. 모든 신규 결과는 미확인 가격 로그에 의존한 조건부 PAPER다.
4. TEMP와 TMP를 새 D: 임시 폴더로 설정하고 python -B test_gap_policy.py 및 python -B test_gap_engine.py를 실행한다. 이 전달 환경에서 두 합성 테스트는 통과했지만 실제 자료 회귀 검사는 아직 실행하지 않았다.
5. README에 기재된 기존 D: 입력 두 개를 읽기 전용으로 확인한다. 경로가 다르면 이전 자료 목록과 해시로 실제 경로를 확인한다. 입력을 새로 만들거나 다시 수집하지 않는다.
6. 비어 있는 새 D: 결과 폴더로 run_gap_sensitivity.py를 실행한다. 0분 허용 대조가 47구간/199이월/26진입/8완료/18미청산, 첫 거래 손익과 단일 계좌 앞부분 MDD를 재현해야 1분/2분 시험 결과를 채택한다. 불일치 시 가드를 제거하지 말고 중단·진단한다.
7. 0/1/2분 비교는 전략 최적화가 아니다. 장중 결측과 세션 시작/끝 결측을 각각 기록하고, 결측 통과 거래를 분리한다. 코드상 세션 양끝의 허용치는 각각 적용되므로 합계 결측 시간도 보고한다.
8. 독립 구간의 완료 거래 합계를 한 계좌의 연간 수익률이라고 표현하지 않는다. 미청산 평가손실과 관측하지 못한 위험을 함께 보고한다.
9. 실제 실행 결과·체결/계좌 원장·검산 보고서만 별도 신규 연구 경로에 게시하고 원격 바이트와 SHA-256을 검증한다. 이 전달 패키지나 기존 결과를 새 백테스트 완료로 보고하지 않는다.

기존 전략/원본/Final OOS/Gateway/다른 수집기는 변경하지 않는다. 실제 주문, 키 사용, 제3자 원문 가격의 공개 재배포는 하지 않는다.
