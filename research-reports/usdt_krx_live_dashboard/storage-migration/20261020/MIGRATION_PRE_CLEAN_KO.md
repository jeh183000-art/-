# C 연구 자료 D 이전 사전 검증

작성일: 2026-10-20

## 복사·검증 결과

- D 보관소 이전 manifest에는 연구 파일 14,373개, 총 5,586,161,608바이트가 기록되어 있다. 별도로 D에 이미 존재하던 6,739개, 474,038,527바이트의 무제한 재검증 자료를 해시 확인 후 재사용했다.
- 복사 당시 SHA-256 검증은 14,370개 성공, 기존 동일 사본 재사용은 3개, 실패는 0개였다.
- 원본과 목적지를 다시 읽어 대조한 결과 14,371개가 기록된 SHA-256과 일치했다.
- 대시보드 시작·정지 런처 2개는 복사 후 D 데이터·로그·캐시 경로와 기존 C Python 가상환경 경로를 사용하도록 의도적으로 수정했다. 두 파일의 수정 전 해시는 이전 manifest에 보존했다.
- 무제한 재검증 자료 6,739개, 474,038,527바이트는 기존 D 사본과 파일별 SHA-256이 모두 일치해 중복 복사하지 않았다.
- 현재 연구용 실행환경인 두 Python `.venv`, Codex의 활성 지침, OpenClaw/WSL 설정 원본은 C에서 보존 대상으로 남긴다.
- D 대시보드 경로는 `D:\Codex_Research\usdt_krx_live_dashboard\app`이며, 검증된 D 아카이브의 프로젝트 사본을 가리키는 junction이다. 대시보드 코드는 프로젝트 상대경로로 데이터베이스와 데이터를 저장한다.
- 런처는 D의 프로세스별 임시·캐시 경로와 D의 앱 작업 폴더를 사용하도록 수정했다. 이번 작업에서는 수집기, 대시보드, 백테스트를 실행하지 않았다.

## WSL 및 OpenClaw

- Ubuntu와 OpenClawGateway 각각에 Microsoft 공식 `wsl --export --vhd` 백업을 시도했으나 두 요청 모두 `Wsl/Service/ERROR_SHARING_VIOLATION`으로 실패했다.
- WSL 배포판 종료, unregister, 초기화, VHDX 직접 복사는 수행하지 않았다.
- Windows OpenClaw 설정의 개인 백업은 D에 저장하고 해시를 확인했다. 비밀정보와 백업 이미지는 이 보고서 및 공개 저장소에 포함하지 않는다.
- 로컬 대시보드 URL 응답 확인은 실패했다. OpenClaw Gateway 복구 및 UI 연결은 아직 확인되지 않았다.

## 저장공간 관찰

복사·재검증 도중 C 여유 공간은 약 5.28GiB에서 약 3.11GiB로 변했다. 파일 전송 목적지는 D였고 C에 대형 연구 산출물을 생성하지 않았다. C의 감소 원인은 별도 시스템/프로세스 변동으로 확정하지 못했다.

이 문서는 사전 원격 보관·검증용 요약이다. C 중복본 정리 전 상태를 기록하며, 개인 경로·파일별 해시·인증정보·데이터 행은 공개하지 않는다.
